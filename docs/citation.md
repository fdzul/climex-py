# How to Cite

If you use **climex** in your research, please cite it.

Dzul Manzanilla, F. A. (2026). *climex: Climate data of Mexico from the NASA
POWER API* (Version 0.2.0) [Computer software].
https://github.com/fdzul/climex-py

```bibtex
@software{dzul_manzanilla_2026_climex,
  author  = {Dzul Manzanilla, Felipe Antonio},
  title   = {climex: Climate data of Mexico from the NASA POWER API},
  version = {0.2.0},
  year    = {2026},
  url     = {https://github.com/fdzul/climex-py},
  license = {MIT}
}
```

Please cite also NASA POWER: *These data were obtained from the NASA Langley
Research Center (LaRC) POWER Project funded through the NASA Earth Science/Applied
Science Program.*
